TLSH模糊哈希云查杀 · Python接入教程

接入方案说明：客户端本地计算TLSH模糊哈希，仅将哈希字符串提交到云端API，不上传原始文件，带宽占用小，保护本地文件。

1. 简介

本API是TLSH模糊哈希云查杀服务。TLSH可以识别恶意文件变种，即使文件被轻微修改，依然可以匹配到相似样本。

接入流程：本地读取文件 → 本地计算TLSH哈希 → POST提交哈希到云端 → 云端比对恶意样本库，返回查杀结果。

2. 基础接口信息

基础地址：https://你的域名.pythonanywhere.com（替换成你自己的网站地址）

接口地址 请求方式 用途
/api/query_hash POST JSON 核心扫描接口，提交TLSH，获取查杀结果
/api/status GET 检测云端服务是否正常运行

3. TLSH判定规则

  • TLSH距离值越小，两个文件相似度越高
  • 默认阈值：50。距离 ≤50 → 判定为恶意样本
  • 文件小于约50字节时，无法生成TLSH，返回TNULL，不能进行比对

4. 扫描接口 /api/query_hash

请求信息

请求方式：POST
Content-Type：application/json

请求JSON参数：

参数名 类型 说明
tlsh 字符串 本地计算出来的TLSH哈希字符串

请求示例

{
    "tlsh": "T1234567890ABCDEFGHIJKLMNOPQRSTUVWXYZ"
}

返回结果示例

6. Python客户端依赖安装

需要两个库：tlsh（计算哈希）、requests（发送HTTP请求）

pip install tlsh requests

7. Python接入完整示例

将下面代码保存为 cloud_scan.py

import tlsh
import requests

# ========= 配置，修改为你的云端地址 =========
API_URL = "https://你的域名.pythonanywhere.com/api/query_hash"
# ===========================================

def get_file_tlsh(file_path: str):
    """读取本地文件，计算TLSH哈希"""
    with open(file_path, "rb") as f:
        file_data = f.read()
    hash_result = tlsh.hash(file_data)
    if hash_result == "TNULL":
        return None
    return hash_result

def scan_file(file_path: str):
    tlsh_str = get_file_tlsh(file_path)
    if tlsh_str is None:
        print("[提示] 文件过小，无法生成TLSH，跳过扫描")
        return

    payload = {"tlsh": tlsh_str}
    resp = requests.post(API_URL, json=payload)
    result = resp.json()
    print("====云端扫描结果====")
    print(result)
    return result

if __name__ == "__main__":
    path = input("请输入待扫描文件完整路径：")
    scan_file(path)

8. 运行使用教程

  1. 安装依赖库：pip install tlsh requests
  2. 修改代码中API_URL，替换为你的云端网址
  3. 打开终端，运行脚本：python cloud_scan.py
  4. 输入待扫描文件的完整路径，回车等待云端返回结果

9. 返回结果说明

status值 含义
malicious 命中恶意样本，判定为恶意文件
clean 库中无匹配样本，暂未发现威胁
  • distance：本次匹配的相似度距离
  • threshold：判定阈值，默认50
  • match.remark：该恶意样本备注信息

10. 常见问题

注意：本项目仅用于安全技术学习研究，禁止扫描、传播真实恶意程序。
  • Q：返回TNULL？
    A：文件太小，TLSH算法无法生成哈希，不能扫描。
  • Q：运行提示ModuleNotFoundError？
    A：tlsh或requests库没有正确安装，重新执行pip安装命令。
  • Q：请求超时？
    A：检查PythonAnywhere网站是否正常，网络是否连通。
